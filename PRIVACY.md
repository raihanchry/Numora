# Privacy Policy for Numora

**Effective Date:** November 23, 2026

Numora is a free, open-source Android calculator application designed with complete user privacy in mind.

## Data Collection
Numora **does not collect, transmit, share, or sell any personal or non-personal user data**.

- No account registration or login is required.
- No analytics, crash-reporting SDKs, advertising networks, or third-party trackers are included.
- No internet permission is requested by the application; Numora works 100% offline.

## Local On-Device Storage
To provide convenience features, Numora stores the following preferences strictly on your device using Android's private `SharedPreferences`:
- Recent calculation history (which you can clear at any time from the History sheet)
- Last selected calculator mode (Basic or Scientific) and angle unit (DEG or RAD)
- Selected theme preference (Light, Dark, or System)

This data never leaves your device and is automatically removed if you clear app storage or uninstall Numora.

## Permissions
Numora does **not** request any Android device permissions.

## Children's Privacy
Because Numora collects no data of any kind, it is safe for users of all ages.

## Open Source Transparency
Numora's source code is publicly available under the GNU General Public License v3.0 (GPL-3.0), allowing anyone to inspect and verify these privacy commitments.

## Changes to This Policy
If future versions introduce any change affecting user privacy, this document will be updated accordingly before release.

## Contact
If you have questions about this Privacy Policy, please open an issue on the project's public GitHub repository.
